# A股资金脉搏

一个本地运行的 A 股盘后研究仪表盘。它每天抓取并汇总：

- 沪深两市成交额；
- 沪深指数口径主力资金净流入/流出；
- 全 A 涨跌家数、涨跌成交量与 ARMS/TRIN；
- IF、IH、IC、IM 主力连续相对现货指数的升贴水；
- 沪深 300 趋势、波动率与行业资金风向；
- 基于四维信号的仓位区间和条件式加减仓方案。
- 资产级选择：空仓、宽基 ETF 候选、股票观察池，以及实际持仓卖出/减仓检查。
- 全 A 主动选股：独立于用户持仓，自动筛选高流动性、趋势向上且风险受控的股票。

程序只使用 Python 标准库，不需要安装第三方依赖。

## 云端日报（GitHub Pages）

仓库内包含静态日报构建器和 GitHub Actions 工作流。部署后：

- 电脑关机、休眠或断网都不影响手机访问；
- 每个交易日北京时间约 16:10 自动抓取收盘数据并发布；
- 网址固定为 GitHub Pages 地址；
- 保留最近快照、主动选股、交易日预测和自动学习权重；
- 不保存个人持仓，也不暴露本地访问令牌。

本地生成静态页面：

```powershell
py -3 build_static.py
python -m http.server 8790 --directory .
```

浏览器打开 `http://127.0.0.1:8790/site/` 预览。

完整部署步骤见 [云端日报部署说明.md](云端日报部署说明.md)。

## 启动

### Windows 桌面版

直接运行交付目录中的 `A股资金脉搏.exe`。桌面版使用原生 WinForms 窗口和内嵌 WebView2，不需要命令行，也不需要单独打开浏览器；关闭窗口时会停止内置服务。

### 本地源码版

在 Windows 中双击 `启动.bat`。程序会打开：

```text
http://127.0.0.1:8765
```

首次启动会自动抓取行情。以后优先使用本地缓存，并在交易时段每 5 分钟、盘后 15:05 后自动更新。关闭启动窗口即可停止本地服务；缓存仍会保留。

只想每日更新一次数据、不启动界面时，可双击 `仅刷新数据.bat`。

如需要让 Windows 每天收盘后自动抓取，右键以普通用户运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\安装每日任务.ps1
```

取消任务：

```powershell
powershell -ExecutionPolicy Bypass -File .\卸载每日任务.ps1
```

## 信号口径

市场评分范围是 -100 到 +100，由四部分组成：

| 维度 | 权重 | 主要内容 |
|---|---:|---|
| 趋势 | 30% | 沪深 300 相对 20 日线、5 日动量、20/60 日线关系 |
| 资金 | 30% | 当日主力净流入、近 5 日累计主力净流入 |
| 广度 | 30% | 涨跌家数差、ARMS/TRIN、过热修正 |
| 期指 | 10% | IF 主力基差百分比 |

ARMS/TRIN 使用：

```text
ARMS = (上涨家数 / 下跌家数) / (上涨股成交量 / 下跌股成交量)
```

低于 1 表示上涨股票拿走了更多成交量，高于 1 表示下跌股票成交更集中。极端值需要结合涨跌家数、指数趋势和量价确认，不能单独交易。

仓位区间的中枢由市场评分决定，并按“稳健 / 均衡 / 进取”三种风险偏好映射。仪表盘会根据总资金和当前权益仓位，把目标缺口拆为首档动作；这不是个股推荐。

资产级决策遵循以下顺序：

1. 评分低于 -45 时优先给“空仓”，不新增股票或 ETF；
2. 评分介于 -45 和 +15 之间时以现金和低仓为主；
3. 评分达到 +15 后，才从高流动性宽基 ETF 和用户观察池中筛选；
4. 个股必须同时满足价格在 20 日线、60 日线上方且近 5 日动量为正；
5. 实际持仓按 20/60 日线状态提示“持有、持有观察、减仓、卖出/清仓”。

软件不会猜测用户持仓。只有在“持仓体检”中录入证券代码后，才能给出具体标的的减仓或清仓状态。

## 主动选股

“全 A 主动选股”每天从成交活跃的股票初筛池中，自动检查：

- 是否位于 20 日线和 60 日线上方，并保持多头排列；
- 5 日和 20 日动量是否为正；
- 是否跑赢沪深 300；
- 20 日波动率和距 20 日高点的回撤；
- 成交额和近期量能；
- ST、停牌、过弱和接近涨停的股票会被剔除。

评分最高的股票会显示触发条件和失效条件。市场评分低于 `+15` 时，即使个股技术面通过，状态也只会是“观察不买”；评分低于 `-45` 时，整体资产选择仍为空仓。

选股完全独立于用户持仓；持仓录入只用于回答“已有持仓是否应卖出或减仓”。

## 数据源

- 指数与期指快照：新浪财经公开行情；
- 沪深指数历史日线、资金流、行业与全市场行情：东方财富公开行情；
- 东方财富全市场分页不可用时，涨跌家数自动切换至新浪全市场列表。

公开接口并非正式商业数据授权，字段、延迟或可用性可能变化。程序会保留最近成功数据，并在“数据源与可用性”中标记正常、缓存或异常。

## 目录

```text
ashare-pulse/
├─ app.py                 # 本地 Web 服务、刷新与调度
├─ market_data.py         # 行情抓取、分页与 ARMS 计算
├─ strategy.py            # 评分、仓位区间和执行规则
├─ asset_selector.py      # ETF候选、股票观察池与持仓体检
├─ active_stock_selector.py # 全A主动选股与趋势评分
├─ storage.py             # 每日快照与本地缓存
├─ desktop.py             # 桌面入口与内置服务
├─ desktop_host/           # 原生 WinForms + WebView2 桌面外壳
├─ web/                   # 无外部依赖的前端
├─ data/                  # 运行后生成的缓存
├─ tests/                 # 核心计算测试
├─ 启动.bat
├─ 仅刷新数据.bat
└─ 安装每日任务.ps1
```

运行测试：

```powershell
py -3 -m unittest discover -s tests -v
```

## 重要限制

这是市场状态研究与仓位纪律工具，不构成证券投资建议，不保证收益。它不替你选择个股，也无法消除数据错误、接口中断、跳空、流动性和模型失效风险。任何买卖决定都应结合个人财务状况、投资期限与风险承受能力独立作出。
